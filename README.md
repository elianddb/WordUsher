# WordUsher
![game logo](https://rutgers.box.com/public/static/bodi6mw4df2imjy477ebglddpv8dkuxp.png)

### Highlights
- Menu screen
- Level select screen
- Wordusher game
- Custom game mode
- Score screen

## Menu Screen
This is the main menu for the game! The user has two buttons to choose from. Either start a new game from a list of predefined levels or create a custom one.\
\
![menu screen](https://rutgers.box.com/public/static/16y0si9vkmnc35leldbupdpyqae9jmx3.png)

## Level Select
This is the level select. Choose from three different levels based on nature, computers and sci-fi. Your best scores are represented in the form of stars below each level icon.\
\
![level select](https://rutgers.box.com/public/static/s5d70hdocbu72lh1q932t946gvn3kb2l.png)

## Custom Game Mode
This is the custom game mode screen! Enter a custom word up to 8 letters of your choosing. The game will automatically generate a level with that word.\
\
![custom game mode](https://rutgers.box.com/public/static/kg8p1xnxhvilf9qxpkux0o94fzvuv4cw.png)

## WordsUsher Game
This is the WordUsher game itself. The user spawns in as a robot tasked with building words. The letters to construct the word are scattered throughout a two-dimensional grid.\
\
![game0](https://rutgers.box.com/public/static/pzbp2i2iet1r1pvkqlh3crmunvmwpgxx.png)
![game1](https://rutgers.box.com/public/static/38m009h7zrt6tvq4ny0lx2q0erksr36j.png)

The controls are straightforward to pick up. The D-Pad provides a traditional form to navigate the grid. The grab icon on the right provides a way to initiate a grab. To choose the direction you want to grab use the D-Pad.\
\
A skip button is available in the bottom-right if you cannot solve the word.\
\
![skip button](https://rutgers.box.com/public/static/tdgn9yxdzg09pet7udeofpnd3ptlou4g.png)

## Score Screen
The score screen appears between word completions and at the end of a level. It offers recurring messages based on the player’s performance. At the end, showing a final score of their cumulative performance.\
\
